# Post captions and shareable messages

Offer text with every finished video, in the user's language, in the style of their earlier posts if you have seen them. Put each text in its own block so it can be copied directly. Use only facts the user gave you. List anything you added so they can remove it.

## Post caption

- First line: the hook. It must work alone, before "more".
- Then what happened or what is happening, short.
- Practical details on their own line for events: date, place, time, price.
- A thank-you line if there are sponsors.
- Tags and hashtags last. Use the ones the user asked for, exactly as written.
- Offer a shorter version when the clip does the talking.

## Group message

Make it readable with no context, since it will be forwarded. WhatsApp shows `*text*` in bold.

```text
*Event name: day, date, time, place*

One sentence on what it is.

*How it works:*
- step
- step

*Entry:* price and what it includes.

Forward this and bring friends!
```

## Private message

Sound like a person: short, one idea, one clear question, one easy way to pass it on.

```text
Hi! On [day] at [time] we are doing [event] at [place].

In short: [one sentence].

Entry is [price]. Are you coming? If you know someone who would like it, send them this.
```

## Comments as content

When a post asks viewers for something, suggest that the user writes the first comment and pins it, then replies and shows the requests in a follow-up story.
