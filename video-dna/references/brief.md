# The brief

Settle this before proposing themes. Look at the request and the folder first, and never ask what you can already see or were already told.

Ask everything in one short round. Use a multiple-choice question tool if one is available, and otherwise a single numbered message. Offer a recommended default per question, so the user can answer "defaults" and move on. If the user says to decide yourself, decide and state your choices.

## What to settle

| Topic | Options | Default |
|---|---|---|
| Purpose and audience | What should a viewer do or feel? First-time viewers or people who already know? | Ask; no default |
| Type | Vlog, reel, promo, reminder, update, aftermovie, comedy, explainer, poster animation, screen loop | Closest recipe in `formats.md` |
| Orientation | Vertical 9:16 (1080x1920), landscape 16:9 (1920x1080), square 1:1 (1080x1080), 4:5 (1080x1350) | Vertical, or landscape for screens |
| Platform | Reels, TikTok, Shorts, YouTube, projector or screen | All three short platforms |
| Length | Target seconds, and number of parts | From the recipe |
| Rhythm | Calm (cuts every 3-5 s), medium (1.5-3 s), fast (0.5-1.5 s), frantic (on every beat) | Fast |
| Motion graphics intensity | See the scale below | Heavy |
| Visual identity | Existing logo, colors, fonts, earlier posts to match, or free choice | Free choice, a new theme |
| Tone | Funny, epic, serious, emotional, informative | From the story |
| Audio | User's tracks, generated music, footage sound only, silent | See below |
| Captions and language | On or off, language, censoring | On for speech, footage language |
| Must-include facts | Names, date, place, price, sponsors, hashtags, call to action | Ask if it is a promo |

Only ask about what matters for this request. A short joke reel does not need twelve questions. For an event promo, the facts are essential and the rest can default.

## Motion graphics intensity

Treat the user's choice as a concrete target:

| Level | Graphics | Typical use |
|---|---|---|
| Light | Captions, a title, an end card | Story carries it, emotional pieces |
| Medium | One graphic every 5-8 s, plus a chapter device | Vlogs, explainers |
| Heavy | One every 2-4 s, persistent HUD or theme element, sounds on each | Default for reels |
| Nonstop | Something moving at all times, layered, kinetic type on every beat | Hype, promos, pure motion graphics |

## Visual identity

If the user has one, ask for logo files (a transparent PNG or SVG), color codes, fonts, and links or screenshots of earlier posts. Extract colors from a supplied logo or post rather than guessing, and match their established look.

If they have none, propose it together with the theme: palette, fonts, animation style. Render a single still frame of each candidate if the choice is hard to describe.

## No material

An empty folder is fine. Say what you can make, and ask whether the user would rather add material first.

**Made entirely in code, free of copyright issues:**

- animated text, shapes, icons, charts, maps, timelines, device mockups and particle effects;
- simple illustrations drawn from shapes, and QR codes;
- sound effects with `scripts/sfx.py`;
- simple original music beds with `scripts/music.py`. These are chiptune or pulse style, usable but plainly not a studio track.

**Not possible from code alone:**

- realistic footage or photographs;
- real people, real places or actual products;
- voiceover, unless the environment has a text-to-speech voice. Ask before using one.

If image, video or voice generation tools are connected, offer them and name what they would be used for. Never present generated images as real photos or real events, never generate images of real people without their permission, and never imitate a brand or a real person.

**What to request.** When a piece needs material you cannot generate, list exactly what would help most, with a target folder and filenames: logo, 3-5 photos, a short clip of a particular thing, and the track for the ending. Then let the user choose between adding it and continuing without it.

**Facts.** With no footage to draw from, facts must come from the user. Ask for them, and do not fill gaps with invented details. The DNA still applies: each graphic carries a true fact or a joke grounded in what you were told.
